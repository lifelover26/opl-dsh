为官方角色绑定执行组合，让不同执行引擎的成员使用官方团队消息和任务工具，并管理跨引擎任务的交付与验收。

入口：**设置 → 协作与自动化 → 角色与执行组合**。先启用 **OPL 执行组合**，再为现有官方角色选择已就绪的组合。绑定用于新会话和新成员，已有会话保持原执行绑定。角色的人设、Skills 和可用工具继续在官方 Agent 预设中管理；需要通信的角色应启用官方成员通信模块。

官方 DSH 保存成员身份、团队消息、任务板与权限。本插件只保存角色到组合的引用，外部会话由 OPL 执行组合关联。外部引擎通过 `opl-harness` MCP 的 `dsh_*` 工具，以当前官方成员身份调用官方协作能力。

关闭本插件后，角色绑定和 OPL 协作工具停止接入，执行组合仍可单独使用。已有官方成员、消息、交付记录与外部会话数据保留。
