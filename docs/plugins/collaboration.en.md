Bind official roles to execution combinations and connect external engines to official DSH team messaging and task tools.

Requires **OPL Execution**. Open **Settings → Collaboration** and select a ready combination for an existing official role. Bindings apply to new conversations and members. Manage personas, Skills and tool access in the official preset editor; roles that exchange messages need the official member communication module.

DSH owns member identities, messages, task boards and permissions. External engines call official tools as their own DSH member through the `dsh_*` tools of the `opl-harness` MCP server.

The plugin also reads the canonical App/Framework Package projection and registers installed, activated and launch-ready standard Agents as official Agent presets. Select MAS, MAG, OBF and other available presets for a new conversation, load their primary Skills through the official Skill system, then bind a ready DSH, Codex or Claude combination for the interactive conversation here. Durable StageRun executors remain defined by each Package contract. Package lifecycle, domain artifacts and quality decisions remain with their owners.

Disabling this plugin removes role bindings and OPL collaboration contributions from the live runtime. Saved records remain, and execution combinations remain independently usable.
