选择模型来源与执行引擎，保存为可复用的执行组合，并在官方对话中使用。

入口：**设置 → 执行与组合**；日常切换使用输入框的模型与执行引擎菜单。模型与凭据仍由模型来源负责，本插件保存组合、外部会话关联和执行记录。

Codex、Claude Code 等执行程序需要在本机就绪。可用范围以组合页面的实际状态为准。关闭本插件后，外部执行适配和组合入口停止加载，历史数据保留；依赖它的 OPL 跨引擎协作暂停。DSH 的原生会话、角色和权限由官方继续管理。

配合 **OPL 跨引擎协作**，可给官方角色绑定执行组合并接入官方团队通信。OPL Gateway 账号由 **OPL DSH 基础增强** 管理，其他模型来源由各自插件管理。
