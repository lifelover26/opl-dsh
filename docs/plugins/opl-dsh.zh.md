在官方 DeepSeek Harness 中连接 OPL Gateway，使用不同的模型与执行引擎，并进行跨引擎任务协作。

| 你要做的事                                        | 使用入口                              |
| ------------------------------------------------- | ------------------------------------- |
| 登录 Gateway，查看账户、用量与分组权限            | 设置 → OPL Gateway                    |
| 管理执行程序、网络代理与模型组合                  | 设置 → 执行与组合                     |
| 在对话中选择 DSH、Codex、Claude Code 等已适配组合 | 输入框的模型与执行引擎菜单            |
| 派发跨引擎任务、继续修改并验收交付                | 对话中的协作工具；设置 → 协作与自动化 |

执行组合绑定精确的模型来源与执行引擎，实际可用范围取决于来源状态、适配器及本机执行程序。官方智能体团队、原生会话与权限继续由 DSH 管理。

关闭本插件后，OPL 的增强入口与协作工具停止加载，已保存的账号设置、执行组合和会话数据保留。Our Free Model 等独立插件由各自的开关管理。
