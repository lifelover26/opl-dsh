在官方 DeepSeek Harness 中管理 OPL Gateway 账号与模型，并提供首启设置、增强层更新、会话统计等通用体验。

账号与分组权限入口为 **设置 → OPL Gateway**。模型供应商及凭据仍由对应来源管理。

执行引擎和组合由 **OPL 执行组合** 提供；角色绑定、团队接入和任务交付由 **OPL 跨引擎协作** 提供。三个插件可在官方插件管理中分别启停，协作插件需要执行插件。关闭基础增强后，OPL Gateway 来源停止服务；执行插件仍可使用其他已就绪的模型来源。

关闭插件保留已有账号设置、组合和会话数据。官方应用与官方插件保持原样。
