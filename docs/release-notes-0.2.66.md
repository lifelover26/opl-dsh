官方 DeepSeek Harness：`{{OFFICIAL_VERSION}}` · OPL 增强：`{{VERSION}}`

OPL DSH 将增强功能拆分为三个可分别管理的 OPL 插件，并新增官方角色与执行组合的绑定及跨引擎团队协作接入。

### 变更

- 插件管理中分别提供 OPL DSH 基础增强、OPL 执行组合和 OPL 跨引擎协作，包含各自的名称、说明、图标和离线详情；安装器统一更新这些插件并保留已有启停选择。
- 可在“协作与自动化 → 角色与执行”中为官方角色选择已就绪的执行组合。官方继续管理角色、人设、Skills、成员、消息、任务和权限；外部引擎可通过官方团队工具参与协作。
- 执行组合与全局默认权限设置保持独立；角色组合的只读限制可以收紧继承权限，不会扩大成员权限。
- 升级时将旧配置中的执行与协作设置迁至对应插件；目标配置已有显式设置时予以保留，并保存迁移前的配置备份。

### 已知限制

- 跨引擎协作依赖 OPL 执行组合，使用 Codex 或 Claude Code 等外部执行程序时，该程序需已在本机就绪。
- 角色绑定仅用于新会话和新团队成员；已有会话继续使用原执行组合。
- 官方桌面及其候选阶段以以上实际版本为准；开发 API 依赖与桌面 feed 分别记录。
- 本地模型 fixture 证明协议、工具和持久化链路，不代表真实 Gateway、外部模型质量或全部 Harness 组合已验收。
- Windows 受限 token 下的 Git Bash 外部程序仍有限制；验收的真实 Git Bash 工具路径使用显式授权的完整访问权限，不自动执行 ACL 修复。
- 新功能的适用范围与限制见对应功能文档及提交；直接打开官方桌面不会运行外部 OPL 更新器。

### 升级
