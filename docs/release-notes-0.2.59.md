### 变更

- 安装时提前准备运行目录；固定版本的模型插件下载遇到部分 GitHub 服务错误时，会尝试通过 GitHub API 获取同一归档。

- 新增 `inspect_mcp_app_host`，可检查当前对话中的工具可用性和资源读取工具，并说明如何使用原工具结果及其提供的应用入口。
- 会话初始化时固定继承的模型选择，避免其他会话更改默认值影响当前会话。

### 已知限制

- 当前 OPL 尚未接通标准 MCP Apps 嵌入式渲染；其他已安装界面的能力不在此诊断范围内。无嵌入式 UI 时仍需通过原工具及其结构化结果或明确提供的应用入口完成交接。
- 超出路由输入上限的内容会在条目解析前被拒绝。
- 官方桌面及其候选阶段以以上实际版本为准；开发 API 依赖与桌面 feed 分别记录。
- 本地模型 fixture 证明协议、工具和持久化链路，不代表真实 Gateway、外部模型质量或全部 Harness 组合已验收。
- Windows 受限 token 下的 Git Bash 外部程序仍有限制；验收的真实 Git Bash 工具路径使用显式授权的完整访问权限，不自动执行 ACL 修复。
- 新功能的适用范围与限制见对应功能文档及提交；直接打开官方桌面不会运行外部 OPL 更新器。

### 升级
