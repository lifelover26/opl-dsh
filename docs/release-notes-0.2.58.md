官方 DeepSeek Harness：`{{OFFICIAL_VERSION}}` · OPL 增强：`{{VERSION}}`

OPL DSH 增强了更新提示与延后安装流程，改善了图片输入、模型目录和 CLI 入口检测，并修复了部分 Gateway 与消息编辑问题。

### 变更

- OPL 会在启动后检查增强更新，并可在通用设置中手动检查或关闭自动检查；发现更新后由用户选择“下次启动时更新”，套件入口会在所有 profile 退出后安装。官方桌面仍使用自身更新机制。
- 图片输入根据模型来源声明和 CLI 能力开放；支持的消息编辑会保留原图片。新增 OFM Crouton Alpha 与 Kilo Code 的组合，并修复已验证 Grok Build 版本的图片输入识别。
- 改进 Gateway 模型目录同步与状态提示，目录读取失败时保留已配置模型；修复部分 Gateway 发现及配置问题。CLI 检测和维护更明确地区分已发现入口与验证通过的入口，并显示实际采用的路径。
- 消息编辑恢复入口改为从对应消息操作；设置导航改为文字显示，不再显示图标。

- Host/Client 类型检查、RPC、模块边界、格式、构建与自动测试：通过
- macOS arm64 与 Windows x64 未修改官方桌面隔离验收：通过

- 联合清单与验收记录随 Release 提供；发布后逐一回读公开资产摘要

### 已知限制

- 延后安装仅适用于更新协议受支持且官方桌面版本匹配的安装；不匹配时需使用完整安装包。
- 图片输入仅适用于来源声明支持图片且 CLI 能力通过检查的组合；不支持的输入会在发送前拒绝。图片消息编辑还要求原附件引用和底层消息身份可核实；其他附件不支持此编辑方式。
- 官方桌面及其候选阶段以以上实际版本为准；开发 API 依赖与桌面 feed 分别记录。
- 本地模型 fixture 证明协议、工具和持久化链路，不代表真实 Gateway、外部模型质量或全部 Harness 组合已验收。
- Windows 受限 token 下的 Git Bash 外部程序仍有限制；验收的真实 Git Bash 工具路径使用显式授权的完整访问权限，不自动执行 ACL 修复。
- 新功能的适用范围与限制见对应功能文档及提交；直接打开官方桌面不会运行外部 OPL 更新器。

### 升级

退出 DeepSeek Harness 后运行最新安装器，或使用 OPL 维护启动入口。更新失败保留当前安装，不替换运行中的 profile；官方桌面由 DeepSeek 原生机制更新。
