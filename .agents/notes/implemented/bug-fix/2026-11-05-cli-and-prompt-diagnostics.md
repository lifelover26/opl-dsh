# CLI 检测、文本准入与 MiniMax 退出状态

已有 CLI 的可用性由实际启动入口和版本回读确定，不以 npm 是否存在为依据。Windows Codex 原生版本目录采用有限范围发现，显式配置始终优先；多个入口不按文件夹名称推断版本或自动切换。安装依赖、更新进程和安装后回读分别报告失败。

外部普通对话以最新真实用户消息为当前输入，先校验当前输入与历史转换结果，再连接 CLI。空白、类型错误和长度超限使用明确输入错误及数值长度诊断，不输出正文，不截断历史或自动换会话。持久 operation 和消息内容保持原值，失败不自动重发。

MiniMax 账号页区分已登录与正在退出，在有限预算内回读对应地区状态；退出命令成功不足以宣告认证已清除。地区选择只管理账号查看范围，自定义程序的内部参数与数据目录需要独立证据，不以对话成功推断版本、退出或工具能力均正常。
