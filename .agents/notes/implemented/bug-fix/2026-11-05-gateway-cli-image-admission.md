# Gateway 目录、CLI 入口与图片发送

Gateway 的凭据就绪、目录读取和模型调用是不同状态。目录请求使用同组有效地址与凭据引用；默认 Anthropic 消息路径由 SDK 追加。迁移只修套件默认配置，不能借机覆盖用户的地址、凭据或显式能力声明。

官方配置解析补入的仅文本默认值不代表用户声明，模型的空输入列表也表示未声明。已知模型可补齐缺失或空列表的图片支持；非空仅文本声明只有在自动目录摘要一致时才可迁移，手动修改的非空声明保留原值。目录摘要读取原保存模型的字段顺序；设置服务的脱敏投影会重建字段，不能用其结果核对既有摘要。

启动迁移全部成功后才标记恢复完成。官方供应商重启或相关设置变更可重新触发失败的恢复；同一时刻只执行一次，持久失败等待下一次相关事件，卸载等待正在执行的恢复并停止后续写入。

CLI 文件存在不代表能运行。维护完成必须刷新版本验证；安装器实际目录与用户配置入口不一致时分别报告，不自动替换。默认入口首次安装后保存验证过的绝对路径，避免自定义 npm prefix 在重启后丢失。

外部图片发送同时要求来源支持和 CLI 公告支持。轮次持久化官方附件引用，发送前从附件服务读取，并在异步读取与会话核验后重查生命周期。图片编辑显式解析同一附件服务完成读取与准入，不能依赖调用插件未声明的直接属性注入。编辑只保留可核对的图片引用；旧记录缺少对应引用时不能降成文字重发。文字轮次保留原指纹及恢复行为。
