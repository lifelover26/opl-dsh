# 官方 DSH 0.2.2 接口适配

DSH 0.2.2 在步骤准备前固定模型与推理档位。组合服务通过官方 `agent/created` 与模型选择入口提交默认档位；`agent/request` 只核验冻结选择并处理编辑事务，不在请求末期修改路线。

官方投影注册返回就绪句柄。等待、任务反馈与统计保留各自的句柄，官方轮次状态通过 Agent registry 的领域接口读取；依赖注入在注册完成后发布。任务反馈的缓存投影升级为版本 3，重建审批的原始序号与工具名称，用于恢复启动期间到达的等待状态。Cordis 的配置读取使用经过 schema 解析的 `effectiveConfig`。

编辑消息行装饰官方 user 条目的组件，保留原注册、注入与 `conversation.chat.user.before` 子插槽所有权，不重复声明子插槽。卸载只恢复仍由本插件持有的组件。无工具审核流携带被审查的真实 Session 身份与 `auto-review` 用途；路线准备仍不创建会话或提供工具。SuperAgent 的完整历史从活动 Session 或官方持久化只读句柄读取，保留事件顺序与索引。

开发依赖与锁文件固定到同一 0.2.2-rc.1 cohort；桌面资格仍运行实时更新源的未修改官方应用。测试 fixture 只证明本地协议与生命周期，不能代替联网模型和本机界面验收。

Windows 安装器在启动官方安装程序前清除比较脚本使用的 Electron Node 标记；增强脚本仍在 Node 模式执行。官方安装失败保留实际退出码，并停止后续增强安装。
