# OFM 2.8.3 Kilo model additions

OFM 2.8.3 adds five Kilo catalog entries that were absent from the suite's Kilo pairing list: Nemotron 3 Nano Omni, Nemotron 3.5 Lightning, North Mini Code, Nemotron 3 Ultra, and the OpenRouter Free router. They are pinned as exact Kilo model values so a catalog refresh cannot silently route them through another harness. Existing OpenCode and Pi entries remain separate routes for the same underlying model ids where those harnesses already own a verified pairing.
