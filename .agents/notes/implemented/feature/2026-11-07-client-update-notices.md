# 客户端发现更新与退出后安装

用户需要在日常打开桌面时发现 OPL 正式发布，而不依赖 Codex Skill 启动。官方桌面更新器只负责官方应用；套件已有的安装与摘要校验继续由 `installer/update.mjs` 持有，Host `src/updates` 负责检查状态和六小时调度，Client 通过 Remote 状态流消费，不轮询或直接下载执行文件。

通用设置承接版本、检查偏好和准备操作，侧边栏提示新版本；协作页移除重复更新区，不新增导航页。后台检查不下载增强包、不退出桌面。显式准备绑定用户看到的版本、原安装身份及逐文件摘要，套件下次启动才消费该计划；运行中 profile、版本不匹配和校验失败拒绝安装。官方桌面版本不匹配时使用完整安装包，本地候选需要显式操作才替换。

断网保留最后一次成功发布信息并显示失败。取消或卸载会取消拥有的请求、等待文件操作结束并释放订阅。验证覆盖 Host 调度与取消、Client 交互与重连、清单校验、待更新计划被修改及运行中拒绝；本机 WinCU 验收由用户另行启动。
