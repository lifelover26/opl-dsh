---
title: OFM LFM3-1.7B 与 Kilo 配对
kind: feature
status: implemented
---

OFM 的公开 Kilo 目录将 `liquid/lfm-3-1.7b:free` 声明为免费文本模型，支持工具与推理；Kilo 目录规则为 `low`、`medium`、`high`，默认 `high`，不提供关闭思考。该精确 ID 配对 Kilo Code 的 OFM Chat 转发，显示为“Kilo LFM3-1.7B”，并继续由实时目录、来源成员资格和转发状态决定可用性。当前固定版本 Kilo ACP 的自定义 provider 没有可写 effort 选项，适配器保留上游默认设置并拒绝显式档位；没有添加未经实测的 variants 或直连路由。
